Manual helper

Steam Access Export

Creates a sanitized steam_access_import_v1 JSON from AppIDs visible on the active Steam page.

  • Advisory-only: ranking impact none.
  • Read-only: no Steam mutations, purchases, wishlist edits, or settings changes.
  • AppID-only: no cookies, tokens, passwords, raw HTML, raw responses, names, or private profile data.
  • Manual fallback stays available: copy or save JSON yourself if direct send fails.
Optional local direct send

Explicit only: pair with Steam Tools on 127.0.0.1, then send the sanitized JSON.

Import-only

No Steam cookies/tokens/raw HTML are sent. Local session tokens stay in popup memory only.

Direct send is optional. Extract JSON first, or use Copy/Save at any time.

Sanitized JSON 0 AppIDs

Open a Steam page, then use the extract button. Nothing runs automatically.
