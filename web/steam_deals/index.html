Paso 2 de 4

🔑 Steam API Key opcional

Con una API Key obtienes datos extra:

  • Ver juegos que ya tienes (para limpiar la wishlist)
  • Mejor detección de biblioteca familiar
  • Nota: la API de Steam no detecta DLCs poseídos, solo juegos

Sin key también funciona para wishlist — solo necesitas que sea pública.

Para obtenerla:

  1. Ve a steamcommunity.com/dev/apikey
  2. Pon cualquier nombre de dominio (ej: localhost)
  3. Copia la key que te da
Paso 3 de 4

💰 IsThereAnyDeal API Key opcional

ITAD agrega datos de otras tiendas:

  • Mínimo histórico — el precio más bajo que ha tenido en Steam
  • Precios multi-tienda — si otra tienda lo tiene más barato ahora
  • Bundles activos — si el juego está en algún bundle

Para obtenerla:

  1. Crea cuenta en isthereanydeal.com
  2. Ve a isthereanydeal.com/dev/app/
  3. Crea una app y copia la API key

Cómo leer las métricas principales
Score Es una recomendación compuesta para priorizar qué revisar primero; no reemplaza tu gusto, solo resume varias señales útiles.
Mínimo histórico Es el precio más bajo detectado antes en Steam. Sirve para comparar si la oferta actual está cerca de su mejor momento.
Antigüedad Son los años desde el lanzamiento. Da contexto sobre qué tan nuevo o veterano es un juego; no significa por sí sola que sea mejor o peor.
Tendencia general Resume si en las últimas corridas aparecieron más o menos ofertas. No representa el precio de un juego individual.
