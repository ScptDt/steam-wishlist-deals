👤 Tu perfil de Steam

Necesitamos tu Vanity URL o Steam ID para encontrar tu wishlist.

Lo encuentras en tu perfil de Steam → la parte final de la URL:

Tambien puede ser tu Steam ID (17 digitos):

💡 Si pegas la URL completa del perfil, se extrae automaticamente.
Paso 2 de 4

🔑 Steam API Key opcional

Con una API Key obtienes datos extra:

  • Ver juegos que ya tienes (para limpiar la wishlist)
  • Mejor deteccion de biblioteca familiar
  • Nota: la API de Steam no detecta DLCs poseidos, solo juegos

Sin key tambien funciona para wishlist — solo necesitas que sea publica.

Para obtenerla:

  1. Ve a steamcommunity.com/dev/apikey
  2. Pon cualquier nombre de dominio (ej: localhost)
  3. Copia la key que te da
Paso 3 de 4

💰 IsThereAnyDeal API Key opcional

ITAD agrega datos de otras tiendas:

  • Minimo historico — el precio mas bajo que ha tenido en Steam
  • Precios multi-tienda — si otra tienda lo tiene mas barato ahora
  • Bundles activos — si el juego esta en algun bundle

Para obtenerla:

  1. Crea cuenta en isthereanydeal.com
  2. Ve a isthereanydeal.com/dev/app/
  3. Crea una app y copia la API key
